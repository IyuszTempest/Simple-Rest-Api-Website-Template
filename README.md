A lightweight, high-performance REST API dashboard template with a clean glassmorphism interface. Designed for managing API keys and showcasing various endpoints such as Anime, AI Tools, and more. It is fully responsive and optimized for instant deployment.

## ⚡ Key Features
* **Simple APIKey System**: Easy-to-use dashboard to manage and display your unique API keys.
* **Clean Categorization**: Organizes endpoints into sections like **Anime** and **AI** for better navigation.
* **Live Status Indicator**: Real-time server status monitoring (Online/Offline).
* **One-Click Execution**: Direct "Execute" links for every API endpoint.
* **Vercel Optimized**: Fully compatible with Vercel for zero-config deployment.

---

## 🛠️ Endpoints Included
* **Anime Section**: Includes random cosplay videos, Jikan Moe search, Livechart integration, and random character images (Neko, Megumin, Waifu).
* **AI Section**: Advanced tools like AiLabs Image/Video generation and DeepImage (Flux) for HD image styling.

---

## 🚀 Deployment to Vercel

This project is ready to be hosted on **Vercel** with minimal effort:

1. **Push your code** to a GitHub repository.
2. **Connect to Vercel**: Login to your Vercel dashboard and click "Add New Project".
3. **Import Repo**: Select this repository.
4. **Deploy**: Click "Deploy" and your API dashboard will be live in seconds!
